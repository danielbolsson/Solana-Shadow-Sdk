Shadow SDK Documentation

The complete reference for integrating private Solana transactions into your application.

Installation

npm install @shadow-sdk/core

Initialization

The entry point for the SDK. Configures the connection to Solana and the Shadow Privacy Program.

constructor(config)

const client = new ShadowClient({
  connection: new solanaWeb3.Connection('https://api.devnet.solana.com'),
  wallet: window.solana,
  programId: new PublicKey('...'),
  circuitsPath: '/circuits'
});
Parameter Type Description
connection Connection Solana web3.js Connection object
wallet WalletAdapter Standard Solana wallet adapter (Phantom, Solflare, etc.)
relayerUrl string Optional. URL of the Relayer service for gasless transactions

async initialize()

Initializes the cryptographic primitives (Poseidon hash) and derives the user's Shadow Identity.

await client.initialize();
console.log('My Shadow ID:', client.getShadowIdentifier());

Core Operations

async deposit(params)

Shields Assets. Converts public SOL into a private commitment in the Shadow Pool.

const txSignature = await client.deposit({
  amount: 1000000000n // 1 SOL (in lamports)
});

async withdraw(params)

Unshields Assets. Generates a ZK-Proof to withdraw funds to a public address without revealing the source deposit.

const txSignature = await client.withdraw({
  amount: 1000000000n,
  recipient: 'DestinAtionAddreSS...'
});

async privateTransfer(params)

Sends funds privately to another user within the pool (Internal Transfer).

const txSignature = await client.privateTransfer({
  amount: 500000000n, // 0.5 SOL
  recipient: 'RecipientShadowID...'
});

Utilities

getShadowIdentifier()

Returns: string (Hex)

Returns the user's current Shadow Public Key derived from their wallet signature.

async getPrivateBalance()

Returns: Promise<bigint>

Calculates the sum of all unspent commitments owned by the user.
